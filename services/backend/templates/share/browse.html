Copy with Rclone (recommended)

The fastest and most reliable method, also for very large data. If the copy is interrupted, run the same command again: only missing or changed files are copied.

  1. Install Rclone (version 1.60 or newer): rclone.org/install
  2. Open a terminal (macOS: Terminal, Windows: PowerShell, Linux: your terminal) in the folder where you want to save the data.
  3. Paste and run this command. The data is copied into the folder {{ download_dir }}.
{{ command_block("command-rclone", commands.rclone_copy) }}

Open in Finder (macOS) / Files (Linux)

Connect to the share as a read-only network drive, then copy folders by dragging them to your computer.

Not available on Windows: File Explorer cannot copy files larger than 50 MB from a network drive like this. On Windows, use Rclone.

macOS

  1. In Finder, press ⌘ + K (or Go → Connect to Server…).
  2. Paste the address below and click Connect. If asked, connect as Guest.
{{ command_block("command-webdav-url", webdav_url) }}

Linux

  1. In Files, open Other Locations and enter the address below under Connect to Server.
{{ command_block("command-webdav-davs", webdav_url.replace("https://", "davs://", 1).replace("http://", "dav://", 1)) }}

Copying many large files this way is slower than Rclone and cannot resume after an interruption.

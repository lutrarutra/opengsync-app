Merge Users

  • Use this when the same person has two accounts, e.g. because of an email alias.
  • Everything the source user owns or authored (projects, requests, samples, libraries, pools, comments, API tokens, ...) is moved to the destination user.
  • The source user is deleted. The destination user keeps its email and password.
  • The destination user gets the more privileged of the two roles and, in groups both users belong to, the stronger affiliation.
  • If both users own a project with the same title, merge or rename those projects first.

How to?
  • The sheet lists every {{ item | lower }} of the request, one per row. Fill in where each one is when you hand it in.
    • {% if form.is_plate %}
  • All plates are 96-well plates (rows A-H, columns 1-12).
    • {% endif %}
  • You can copy-paste the {{ set_title }} and {{ position_title }} columns from Excel or another spreadsheet.
Columns
  • {{ item }} read-only
    • The {{ item | lower }}s of the request, shown by name (with the ID where two have the same name). They cannot be changed here.
  • {{ set_title }} optional
      {% if form.is_plate %}
    • The name or barcode written on the plate, e.g. plate_1.
    • Leave it empty if everything is on one plate. All rows with an empty {{ set_title }} are on the same plate.
      • {% else %}
    • The name of the box, rack or bag the tube is in, e.g. box_1.
    • Leave it empty if all tubes come together. All rows with an empty {{ set_title }} belong to the same set.
      • {% endif %}
  • {{ position_title }} required
      {% if form.is_plate %}
    • The well of the {{ item | lower }}: a row letter A-H followed by a column number 1-12, e.g. A1, B12 or H7.
    • Leading zeros are allowed (A01 is A1), and so is lower case.
    • Two {{ item | lower }}s cannot be in the same well of the same plate.
      • {% else %}
    • What is written on the tube, e.g. a number 1, 2, ... or a short label.
    • Two {{ item | lower }}s cannot have the same label in the same tube set. Labels that differ only in upper/lower case count as the same.
      • {% endif %}

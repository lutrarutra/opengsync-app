How to?
  • Add one row per sample. Copy-paste from Excel or another spreadsheet works.
    • {% if project_id %}
  • To reuse samples of the project, start typing a sample name and pick it from the list, or copy the names from the Project Samples tab.
  • A name that is not a sample of the project creates a new sample. The list shows it as Create new and the cell marks it as new.
    • {% else %}
  • The project is new, so every sample in the spreadsheet is a new sample.
    • {% endif %}
Columns
  • Sample Name required
    • The name of the biological sample, e.g. the tissue, cell line or condition with a replicate number.
    • At least 4 characters: letters, numbers and underscores. Other characters, e.g. spaces, are replaced with underscores.
    • Each sample appears only once.
      • {% if project_id %}
    • Rejected samples of the project cannot be reused, please give the sample another name.
      • {% endif %}
  • Organism required
    • The organism the sample comes from. Its reference genome is used for the analysis.
    • Select Custom if the organism is not listed.
